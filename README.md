# Roadbook (formerly ONCourse)

Treatment maps for cancer care. Roadbook lets an oncologist turn a treatment plan into a one-page map a patient can follow: every phase in order, the decision points, and why the plan was chosen.

- Live site: https://allentheli.github.io/Roadbook/
- How it is built and maintained: `CLAUDE.md` and `UPDATING.md`
- Sources for every pathway: `references.html` and `verification-log.md`
- Terms: `disclaimer.html` and `LICENSE` (all rights reserved)

Roadbook is a static site with no server, accounts, or analytics. Nothing a user types leaves their browser.
